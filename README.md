## Overview

zEdit is a next-generation replacement for xEdit/TES5Edit with a module architecture, visual record diffing, built-in merge patch generation, and a JavaScript scripting engine for automated edits.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **zEdit** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Module System** | Load patcher and utility modules from the community module library |
| **Record Diff** | Side-by-side visual comparison of record changes between plugin versions |
| **Merge Patch** | Generate compatibility patches that combine multiple conflicting mods |
| **JS Scripting** | Write automation scripts against the full plugin record tree in JavaScript |
